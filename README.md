# XRPL Mobile Engine (Android PWA)

Aplicación móvil optimizada para Android que conecta directamente con el motor de escaneo XRPL y te muestra en pantalla de forma limpia, táctil y sin enredos de Telegram:
- Conteo real de direcciones procesadas.
- Velocidad de escaneo (hashes/s).
- Últimas semillas y balances detectados.
- **Botón de Copiar y Pegar JSON** para exportar los datos al instante.

## Instalación en tu Celular Android:
1. Abre el enlace de la app en **Google Chrome** para Android.
2. Toca el menú de los 3 puntos arriba a la derecha.
3. Selecciona **"Instalar aplicación"** o **"Agregar a la pantalla principal"**.
4. ¡Listo! Tendrás una app nativa en tu celular para ver el motor en tiempo real.
